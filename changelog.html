Changelog

What's new & fixed.

Every release, every meaningful change. Shipping features and tightening screws.

Currently shipping · v0.1.2
  • v0.1.2 April 26, 2026 · Polish

    New icon, cleaner onboarding.

    • NewBrand-new Paralingo app icon — violet→magenta squircle with the P + speech-bubble + sound-wave glyph. Replaces the legacy Paravoice icon left over from the rebrand.
    • Fix“RECOMMENDED” badge no longer wraps to two lines on the model picker during onboarding. All six model cards now line up with consistent height regardless of which one is the recommended pick.
    • FixLong model names (Large v3 Turbo) gracefully shrink/wrap inside their card instead of overflowing.
  • v0.1.1 April 25, 2026 · UI polish

    Translate ↔ Voice-only mode.

    • NewSegmented mode toggle at the top of the menu-bar dropdown. Switch between full Translate mode and Voice-only (transcription, no translation) with one tap. Persists across launches.
    • FixSettings: Translation, General, Hotkey, Paste, Model and Audio tabs all redrawn against the production design language. Tightened spacing, consistent type scale, native-feeling form controls.
    • FixResolved Swift 6 MainActor crossings, deprecated Text+ warnings, and an OSAllocatedUnfairLock isolation issue. 0 warnings in Release.
  • v0.1 April 22, 2026 · Early access launch

    Speak any language. Paste any language.

    • NewVoice-to-text dictation powered by WhisperKit (Large v3 Turbo) running on the Neural Engine — 99 source languages.
    • NewOn-device translation via Apple's Translation framework — 20 target languages, offline after first download.
    • NewHold-to-speak hotkey (default ⌥). Release, and the translated text pastes at your cursor anywhere on macOS.
    • NewMenu-bar language picker with source + target pills, single-tap swap button, auto-detect source via Whisper.
    • NewSkip-when-same toggle — speak in your target language and the transcript passes through untouched.
    • NewOnboarding with a dedicated language-pair setup step.
    • NewSettings → Translation tab with live "Try it" panel, status indicator (ready / downloading / not-available), and skip-when-same toggle.
    • NewSearchable local history — stores the original transcript, the pasted translation, and the language pair per entry.
    • NewRecording overlay with 10 visual styles (from Paravoice's overlay gallery).
    • NewPer-app language rules: WeChat in Chinese, WhatsApp in Spanish, Slack in English. Paralingo looks up the rule when the target app is focused and uses it for that one paste.
    • NewHeadless self-test mode (--smoke-test) that validates the whole pipeline end-to-end in about 13 seconds.
  • Coming Roadmap
